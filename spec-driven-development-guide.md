# Spec-Driven Development for Junior Developers

## Why Specifications Matter
When junior developers work with AI coding agents (such as Claude Code or Cursor), vague prompts often lead to hallucinations, broken imports, and architectural drift.

## The 4-Step Spec Workflow
1. **Constitution**: Define architectural rules (e.g. tech stack, forbidden packages).
2. **Requirements**: Detail user stories with clear acceptance criteria.
3. **Solution Design**: Outline API schemas, data models, and component tree before code is written.
4. **Task Decomposition**: Break work into atomic, single-responsibility tasks for the coding agent.

Following this workflow prevents AI hallucinations and produces production-grade code.
